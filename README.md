# Навыки AIRL

Шесть навыков для Claude в VS Code. Доводят идею до работающего продукта, помогают
опубликовать его в интернете и проверить код, прежде чем развивать дальше.

**Всё происходит в переписке.** Claude сам задаёт вопросы, сам собирает продукт, сам
показывает результат таблицей в чате. Открывать файлы и разбираться в коде не нужно.
Технических знаний не требуется.

```
/airl-start «сайт для записи в барбершоп»
```

Одна команда — и дальше Claude ведёт вас за руку через три шага.

---

## Что внутри

| Навык | Что делает | Сколько занимает |
|---|---|---|
| **`/airl-start`** | Ведёт через все три шага подряд, с остановкой после каждого | около часа |
| **`/airl-design`** | Шаг 1. Спрашивает, что за продукт и для кого. Собирает экраны, цвета, тексты кнопок | 10 минут |
| **`/airl-architecture`** | Шаг 2. Спрашивает про пользователей, данные и бюджет. Выбирает технологии с ценой и собирает рабочую версию | 30–60 минут |
| **`/airl-security`** | Шаг 3. Проверяет ключи, доступы и расходы. Отвечает прямо: можно показывать людям или нет | 15 минут |
| **`/airl-deploy`** | Публикация. Даёт выбор площадки, выкладывает продукт и сам проверяет живой адрес | 15–30 минут |
| **`/airl-code-review`** | Проверка кода. Находит, где продукт сломается, где затормозит при росте и где его страшно менять | 20–40 минут |

Каждый навык работает и отдельно. В готовом проекте можно запустить только
`/airl-security`, не проходя остальное.

---

## Как выглядит работа

Claude задаёт вопросы по одному, с готовыми вариантами — отвечать можно буквой:

```
Вопрос 3 из 6 · Где будут храниться данные?

A) Готовое облачное хранилище, бесплатно до тысячи пользователей — рекомендую
B) Своя база на своём сервере
C) Хранить ничего не нужно
D) Свой вариант

Рекомендую A: для первой версии хватает с запасом, настраивается за час,
платить начнёте только при реальном росте.
```

Не знаете, что выбрать — напишите «не знаю». Claude возьмёт рекомендацию и объяснит,
почему она разумная.

Результат каждого шага показывается прямо в чате таблицей: экраны, цвета, тексты
кнопок, стоимость в месяц, найденные проблемы безопасности.

## Установка

Нужна один раз. После этого навыки работают во всех ваших проектах.

### Шаг 1. Расширение Claude в VS Code

Откройте VS Code. Нажмите **Cmd + Shift + X** (на Windows **Ctrl + Shift + X**) —
откроется поиск расширений.

Наберите **Claude Code**. Установите расширение от издателя **Anthropic**.

Справа появится значок Claude. Нажмите на него и войдите в свой аккаунт.

### Шаг 2. Откройте терминал

Меню VS Code: **Terminal → New Terminal**. Внизу появится чёрное окно.

### Шаг 3. Вставьте одну команду

```bash
cd ~/Downloads && git clone https://github.com/aza9908/airl-vibecoding.git && cd airl-vibecoding && bash install.sh
```

Должно появиться: `Готово. Установлены навыки AIRL`.

### Шаг 4. Перезагрузите окно

Нажмите **Cmd + Shift + P** (на Windows **Ctrl + Shift + P**), наберите
`Developer: Reload Window`, нажмите Enter. Окно моргнёт.

Без этого шага навыки не появятся.

### Шаг 5. Проверьте

Откройте панель Claude справа и наберите `/airl-start`. Под полем ввода должна
появиться подсказка с описанием на русском. Значит, всё готово.

## Новый проект

Создайте пустую папку и откройте её в VS Code: **File → Open Folder**.

В панели Claude:

```
/airl-start «сайт для записи в барбершоп»
```

Дальше отвечайте на вопросы. Claude сам проведёт через дизайн, сборку и проверку
безопасности, а в конце предложит опубликовать продукт в интернете.

---

## Существующий проект

Навыки работают и с готовым кодом. Откройте папку проекта в VS Code и запустите
тот навык, который нужен.

**Хотите добавить новую возможность:**

```
/airl-start
```

Claude сначала изучит код, покажет, что уже сделано, и спросит, что нужно добавить.
Переписывать существующее без вашего согласия он не будет.

**Хотите переделать внешний вид:**

```
/airl-design
```

Claude найдёт существующие экраны, цвета и шрифты, покажет их и спросит, что менять.

**Хотите проверить безопасность перед запуском:**

```
/airl-security
```

Работает на любом проекте, даже если он собран не через эти навыки. Проверит ключи
доступа, права пользователей и расходы, часть проблем исправит сам, по остальным даст
пошаговую инструкцию.

Это самый частый сценарий для готовых проектов — начните с него.

**Хотите понять, можно ли этот код развивать дальше:**

```
/airl-code-review
```

Это не про безопасность, а про всё остальное: где продукт сломается на пустом
списке или двойном клике, где затормозит на тысяче записей, где одну правку
придётся размазывать по пяти файлам. Особенно полезно, если код писал фрилансер
или ИИ и никто в команде не знает, как он устроен.

Claude запустит сборку и тесты, попробует сломать продукт сам и покажет таблицу:
что сломается, что случится и кто чинит. Мелкое исправит после вашего «да», по
одной находке, с проверкой после каждой. Переписывать архитектуру не станет —
предложит план и цену в часах, решение за вами.

Можно проверять не весь проект, а только последние правки:

```
/airl-code-review изменения
```

## Публикация в интернете

В конце Claude предложит выложить продукт по ссылке. Это делает навык `/airl-deploy` —
его можно запустить и отдельно, на любом готовом проекте:

```
/airl-deploy
```

Claude задаст один вопрос и предложит выбор из трёх площадок:

- **Firebase** — всё в одном месте: сайт, база данных, вход по логину. Бесплатно
  на старте, ссылка через десять минут. Подходит большинству проектов.
- **ps.kz** — казахстанский хостинг. Данные остаются в Казахстане, удобно с доменом
  в зоне .kz. От ~384 ₸ в месяц. Claude уточнит, обычный у вас хостинг или сервер:
  разница важная, на обычном нельзя запускать программы.
- **Supabase** — настоящая база с таблицами и отчётами. Важно: Supabase хранит данные,
  но сайты не размещает, поэтому идёт в паре с Firebase или ps.kz. Claude скажет
  об этом сам и не даст выбрать вариант, который оставит вас без адреса.

Не знаете, что выбрать — скажите «не знаю». Claude возьмёт рекомендацию под ваш
проект и объяснит выбор.

Публиковать без пройденной проверки безопасности Claude не станет. Перед публикацией
предупредит: продукт увидит любой человек со ссылкой. И напомнит поставить потолок
расходов, если используются платные сервисы.

После выкладки Claude сам откроет получившийся адрес и проверит, что продукт реально
работает. «Команда отработала без ошибок» готовым результатом не считается.

## Что появится в папке проекта

```text
DESIGN.md          экраны, цвета, тексты кнопок
ARCHITECTURE.md    на чём собрано, сколько стоит, план сборки
SECURITY.md        что проверили и что исправили
REVIEW.md          где код может сломаться и что с этим сделали
```

Плюс сам код продукта.

Читать эти файлы необязательно — всё главное Claude показывает прямо в чате. Но они
пригодятся, когда к проекту подключится ещё кто-то.

## Если что-то не работает

**Навыки не появились после установки.**

```bash
ls ~/.claude/skills
```

Должно вывести `airl-architecture`, `airl-code-review`, `airl-deploy`, `airl-design`,
`airl-security`, `airl-start`.
Пусто — повторите шаг 3. Список есть, а навыков не видно — вы пропустили шаг 4,
перезагрузите окно.

**Пишу `/airl-start` в терминале, ничего не происходит.**
Навыки набираются в панели Claude справа, а не в чёрном терминале снизу.

**Ошибка `command not found: git`.**
Установите git с [git-scm.com](https://git-scm.com) и повторите шаг 3.

**Claude отвечает не на русском.**
Напишите ему: «Отвечай на русском языке».

## Обновление

```bash
cd ~/Downloads/airl-vibecoding && git pull && bash install.sh
```

И снова перезагрузите окно VS Code.

## Удаление

```bash
rm -rf ~/.claude/skills/airl-*
```

Ваши проекты не пострадают — удаляются только навыки.
