# Навыки AIRL — версия для воскресного интенсива

Короткая предсказуемая дорожка: за одно занятие участник получает работающий
продукт по ссылке `название.web.app` — со входом через Google и сохранением данных.

Отличия от основного набора:

| | Основной набор | Интенсив |
|---|---|---|
| Выбор технологий | под бюджет и задачу | зафиксирован: React + Firebase |
| Площадка | Firebase, ps.kz, Supabase | только Firebase Hosting |
| Адрес | любой, свой домен | только `….web.app` |
| Вход | любой | только через Google |
| Настройка консоли Firebase | — | пошаговый чек-лист с каждой галочкой |
| Частые поломки входа и доступа | — | готовая таблица «симптом → что делать» |
| Вопросов в дизайне / архитектуре | 7 / 6 | 5 / 3 |
| Экранов в первой версии | сколько нужно | 2–3, один из них — вход |
| Публикация | отдельный шаг в конце | уже в первой части сборки |
| `/airl-deploy`, `/airl-code-review` | есть | нет — показываются в конце как часть основного курса |
| Работа с готовым кодом | есть | нет, только новый проект |

## Перед занятием — у участника должно быть

- **VS Code** с расширением **Claude Code** и вход в аккаунт Claude
- **Node.js 20+** с [nodejs.org](https://nodejs.org) (LTS) и **git**
- **Личный аккаунт Google** (@gmail.com) — рабочие часто запрещают создавать проекты
- Браузер, в котором разрешены всплывающие окна (нужны для входа через Google)

## Установка

В терминале VS Code (**Terminal → New Terminal**):

```bash
cd ~/Downloads && git clone https://github.com/aza9908/airl-vibecoding.git && cd airl-vibecoding && bash workshop/install.sh
```

Затем **Cmd + Shift + P** (Windows: **Ctrl + Shift + P**) → `Developer: Reload Window`.

На Windows, если терминал ругается «выполнение сценариев отключено», один раз:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

## Запуск

Создайте пустую папку, откройте её (**File → Open Folder**) и в панели Claude:

```
/airl-start «сайт для записи в барбершоп»
```

## Как идёт сборка

1. **Дизайн** — 5 вопросов, 2–3 экрана.
2. **Сборка на Firebase**:
   - участник создаёт проект в консоли Firebase — Claude ведёт по каждой галочке
     (выключить Analytics, зарегистрировать сайт, нажать Get started в
     Authentication, включить Google с почтой поддержки, создать Firestore в
     production mode);
   - один раз выполняет `npx firebase login` в терминале;
   - Claude собирает каркас и сразу публикует на `web.app`;
   - вход через Google, проверка на `localhost` и на `web.app`;
   - главное действие с сохранением в Firestore, правила доступа, проверка вторым
     аккаунтом.
3. **Безопасность** — шесть пунктов, прямой ответ «можно давать ссылку или нет».
4. **Итог и «что дальше»** — что есть в основном наборе навыков.

## После интенсива — переход на основной набор

```bash
cd ~/Downloads/airl-vibecoding && git pull && bash install.sh
```

Основной набор перезапишет навыки интенсива и добавит `/airl-deploy` и
`/airl-code-review`. Проекты, собранные на интенсиве, продолжают работать.
